## Developer surface

- There is no MoonFruit API. No OpenAPI, AsyncAPI, GraphQL, MCP server, agent card,
  SDK, or developer portal is published. api., developer. and docs.moonfruit.com are
  wildcard DNS records that return the marketing homepage with HTTP 200.
- The site is WordPress; the stock WordPress REST API index responds at
  https://moonfruit.com/wp-json/ but exposes only WordPress core and third-party
  plugin namespaces. It is not a MoonFruit product and is not documented by MoonFruit.
- Directory content is otherwise reachable only as HTML pages and the RSS feed.
